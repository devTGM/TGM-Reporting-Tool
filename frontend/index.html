Partitioning & View Architecture
Optimized for Looker Studio
BigQuery tables are created with native DAY partitioning on date and clustering on platform, client_id, campaign_name for ultra-low query latency and minimal Looker Studio scan costs.
Automated Looker Views Created:
  • v_looker_studio_daily_overview: Flat daily cross-channel view with all 11 raw metrics, 8 nomenclature dimensions, and 17 safe-calculated ratios.
  • v_looker_studio_weekly_nomenclature: Weekly rollup by the 8 taxonomy dimensions (Category, Product, Funnel, Sale/Offer, Audience, Hook, Format, Landing Page).
  • v_looker_studio_creative_performance: Creative/video performance table with 3s video play rates (Thumbstop), 15s ThruPlays, and cost efficiencies.
CREATE TABLE IF NOT EXISTS `PROJECT.tgm_reporting.unified_ad_performance` ( record_id STRING NOT NULL, date DATE NOT NULL, client_id STRING NOT NULL, platform STRING NOT NULL, -- Meta, Google, LinkedIn, TikTok, Snapchat campaign_name STRING, adset_name STRING, ad_name STRING, -- 8 Nomenclature Dimensions category_collection STRING, product_name STRING, funnel STRING, sale_offer STRING, audience_type STRING, concept_angle_hook STRING, format STRING, landing_page STRING, -- 11 Input Raw Metrics spend FLOAT64, purchases_conversion_value FLOAT64, purchases FLOAT64, landing_page_views INT64, reach INT64, impressions INT64, link_clicks INT64, video_plays_3s INT64, thruplays_15s INT64, adds_to_cart INT64, checkouts_initiated INT64, -- 17 Formulated Metrics purchase_roas FLOAT64, cost_per_purchase FLOAT64, avg_purchase_conversion_value FLOAT64, purchase_rate_per_lpv FLOAT64, cost_per_lpv FLOAT64, lpv_rate_per_link_clicks FLOAT64, frequency FLOAT64, cpm FLOAT64, cpc FLOAT64, ctr FLOAT64, video_plays_3s_rate_per_impressions FLOAT64, cost_per_video_play_3s FLOAT64, cost_per_thruplay_15s FLOAT64, cost_per_add_to_cart FLOAT64, add_to_cart_pct FLOAT64, cost_per_checkout_initiated FLOAT64, checkout_initiated_pct FLOAT64 ) PARTITION BY date CLUSTER BY platform, client_id, campaign_name;

Looker Studio Reporting Hub

Connect BigQuery directly to Looker Studio and embed interactive dashboards

Open Looker Studio BigQuery Connector →
1. Connect BigQuery in Looker Studio
  1. Go to Looker Studio and click Create → Data Source.
  2. Select the official BigQuery connector by Google.
  3. Choose My Projects → Select your GCP Project → Dataset: tgm_reporting.
  4. Select the Table unified_ad_performance or View v_looker_studio_daily_overview.
  5. Click Connect in the top-right corner.
2. Looker Studio Calculated Fields

Add these calculated fields in Looker Studio so aggregated metrics recalculate accurately at any date range or filter:

Purchase ROAS: SUM(purchases_conversion_value) / NULLIF(SUM(spend), 0) Cost per Purchase (CPA): SUM(spend) / NULLIF(SUM(purchases), 0) Purchase Rate per LPV (%): (SUM(purchases) / NULLIF(SUM(landing_page_views), 0)) * 100 Thumbstop Rate (%): (SUM(video_plays_3s) / NULLIF(SUM(impressions), 0)) * 100 Add to Cart %: (SUM(adds_to_cart) / NULLIF(SUM(landing_page_views), 0)) * 100
